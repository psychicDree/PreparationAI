## 🚀 **Ready to Use**

### **Quick Start**

1. **Setup Environment**:
   ```bash
   ./scripts/setup-env.sh --all
   ```

2. **Validate Configuration**:
   ```bash
   cd backend && go run cmd/validate-config.go
   ```

3. **Start Services**:
   ```bash
   # Backend
   cd backend && go run cmd/main.go
   
   # Frontend
   cd frontend && npm run dev
   ```

### **Environment Variables Required**

#### **Essential Variables** (Must be set):
- `OPENAI_API_KEY` - Get from https://platform.openai.com/api-keys
- `STRIPE_SECRET_KEY` - Get from https://dashboard.stripe.com/apikeys
- `STRIPE_PUBLISHABLE_KEY` - Get from https://dashboard.stripe.com/apikeys
- `DB_PASSWORD` - Your PostgreSQL password
- `JWT_SECRET` - Auto-generated by setup script

#### **Optional Variables** (Have defaults):
- `NODE_ENV` - Environment mode (development/production)
- `PORT` - Server port (default: 8080)
- `DB_HOST` - Database host (default: localhost)
- `VITE_API_URL` - Frontend API URL (default: http://localhost:8080/api/v1)
